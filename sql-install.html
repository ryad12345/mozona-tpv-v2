⚡ FIX CRÍTICO: Email OTP no llega — Cómo solucionarlo en 2 minutos

Síntoma: La pantalla "Verifica tu correo" aparece pero el email nunca llega.
Causa: La Edge Function send-email solo se dispara si el frontend la llama. Si el usuario cierra la app o hay un error de red, el email se queda en cola (estado pending) sin enviarse.
Solución DEFINITIVA: Configurar un Database Webhook en Supabase (2 minutos, sin tocar SQL).
A

Método RECOMENDADO: Database Webhook (2 minutos)

Ve al panel de Supabase → Database → Webhooks → Create a new hook:

  • Name: auto-send-email
  • Table: email_outbox
  • Events: ☑ INSERT (solo insert)
  • Type: Supabase Edge Function
  • Function: send-email

Save. A partir de ahora CADA INSERT en email_outbox dispara automáticamente la Edge Function, sin depender del frontend.

B

Alternativa: Aplicar SQL #53 (trigger pg_net)

Si el Webhook UI no funciona por algún motivo, descarga SQL #53 y aplícalo en SQL Editor. Esto crea un trigger PostgreSQL con pg_net que llama a la Edge Function automáticamente.

Después de aplicarlo, ejecuta esta función UNA vez (como superadmin en SQL Editor) para configurar la service_role_key:

SELECT rpc_set_email_trigger_config(
    'https://hcqkpokodrqimkulporw.supabase.co',
    'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...tu-service-role-key-completa...'
);
C

Comprobar que funciona

Tras configurar el webhook (o aplicar SQL #53):

  • En Supabase → Edge Functions → send-email → Logs, deberías ver invocaciones cada vez que se genera un OTP
  • En Supabase → Table Editor → email_outbox, el estado debería cambiar de pending a sent en segundos
  • El email debería llegar a la bandeja en menos de 30 segundos
  • El frontend ahora también hace reintentos (3 intentos con backoff exponencial) como fallback

🚀 Configuración de Resend (3 minutos)

Por qué Resend: Plan gratuito = 100 emails/día, sin tarjeta de crédito, entrega profesional sin marcas de agua.
1

Crea cuenta gratuita en Resend

Ve a https://resend.com/signup y registra tu cuenta con el email rofixinsta@gmail.com.

2

Obtén tu API Key

En el dashboard de Resend → API Keys → Create API Key. Copia la clave (empieza por re_...).

3

Configura el Secret en Supabase Edge Functions

Ve a Supabase → Edge Functions → Manage Secrets. Añade:

RESEND_API_KEY = tu clave de Resend
RESEND_FROM_EMAIL = onboarding@resend.dev (dominio de prueba) o tu dominio verificado

4

Despliega la Edge Function

Ve a Edge Functions → New function → nombre: send-email. Pega el código Deno del archivo SQL #52 (sección 6 del archivo).

5

Programa el cron (opcional)

Para que los emails se envíen automáticamente cada minuto, en Supabase SQL Editor ejecuta:

SELECT cron.schedule('send-emails', '* * * * *', $$ ... $$);

(El código exacto está en SQL #52 sección 6.)

Mientras tanto: La Edge Function se puede invocar manualmente desde cualquier cliente via:
supabase.functions.invoke('send-email', { body: {} })
El frontend ya hace esto automáticamente tras generar el código OTP.
